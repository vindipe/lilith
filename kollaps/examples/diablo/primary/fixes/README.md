# Diablo / Minion runtime fixes

This directory contains files that are copied into the primary container and
then injected into the Diablo/Minion runtime.

Most files in this directory are static patches, installers, or workload
definitions.

The file named lilith is intentionally not versioned. It is generated by
run.sh before the Docker build step by copying the blockchain-specific worker
from misc/lilith/lilith-<implementation>.

Examples:

- misc/lilith/lilith-poa
- misc/lilith/lilith-algorand
- misc/lilith/lilith-diem
- misc/lilith/lilith-quorum
- misc/lilith/lilith-solana

The generated fixes/lilith file is ignored by .gitignore.
